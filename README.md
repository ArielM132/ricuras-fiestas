# Ricuras Fiestas | Eventos Inolvidables

Sitio web profesional para **Ricuras Fiestas**, una empresa familiar dedicada a la organización integral de eventos con más de 35 años de experiencia.

## ✨ Características
* **Diseño Responsivo:** Adaptado para celulares, tablets y computadoras.
* **Modo Claro/Oscuro:** Interruptor personalizado para cambiar la estética visual.
* **Secciones:** Inicio (Hero), Servicios detallados y Contacto directo.
* **Tecnologías:** HTML5, CSS3 (Variables y Flexbox) y JavaScript Vanilla.
