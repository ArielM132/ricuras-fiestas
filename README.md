# Ricuras Fiestas

Sitio web profesional desarrollado para **Ricuras Fiestas**, una empresa familiar de Corrientes Capital dedicada a la organización integral de celebraciones y eventos.

La página presenta los servicios del negocio de forma clara, visual y responsiva, facilitando que cada visitante conozca las propuestas disponibles y solicite una cotización personalizada mediante WhatsApp.

## Ver el proyecto

La versión publicada se encuentra disponible en:

### [Visitar Ricuras Fiestas](https://ricurasfiestas.videoariel132.workers.dev/)

## Objetivo del sitio

El proyecto fue diseñado para transformar las visitas en consultas reales, reuniendo en una misma experiencia toda la información necesaria para organizar un evento y ofreciendo accesos directos para solicitar disponibilidad, reservar una fecha o recibir una cotización personalizada.

## Servicios presentados

- Quincho para celebraciones.
- Perniles y acompañamientos.
- Alquiler de mobiliario y elementos para eventos.
- Organización y ambientación de eventos.
- Catering y propuestas gastronómicas.

## Funcionalidades principales

- Navegación mediante tarjetas visuales de servicios.
- Información organizada por secciones.
- Galerías fotográficas de trabajos y propuestas reales.
- Precios, promociones, extras y detalles de cada servicio.
- Botones de contacto y cotización directa por WhatsApp.
- Enlaces a las redes sociales del negocio.
- Diseño adaptable a celulares, tablets y computadoras.
- Animaciones y microinteracciones sutiles.
- Navegación clara y estructura HTML semántica.

## Tecnologías utilizadas

- **HTML5:** estructura semántica y contenido del sitio.
- **CSS3:** identidad visual, Flexbox, diseño responsive y animaciones.
- **JavaScript:** interacciones, navegación y comportamiento dinámico.
- **Cloudflare Workers:** publicación y distribución del sitio web.

El proyecto fue desarrollado sin frameworks ni dependencias externas obligatorias.

## Ejecutar el proyecto localmente

Cloná el repositorio:

git clone https://github.com/ArielM132/ricuras-fiestas.git

Ingresá en la carpeta:

cd ricuras-fiestas

Después podés abrir `index.html` directamente en el navegador o utilizar la extensión **Live Server** de Visual Studio Code.

## Enfoque de diseño

La interfaz busca transmitir cercanía, confianza y profesionalismo mediante una estética cálida y festiva. La jerarquía visual prioriza los servicios, la información comercial y los llamados a la acción, evitando sobrecargar la experiencia.

El diseño se desarrolló con un enfoque *mobile first*, cuidando la legibilidad, los espacios, el contraste y la facilidad de contacto desde cualquier dispositivo.
